### MY SIDE PROJECT: OPTICA (in progress, not started yet)

Optica is an AI-Powered Production Incident Intelligence Platform for engineering/SRE teams.
Tagline: "See every incident down to the root"

WHAT IT DOES:
- Engineers create incidents, upload logs/runbooks
- System uses Hybrid RAG (BM25 + semantic search via LangChain EnsembleRetriever) to find similar historical incidents
- AI calls live tools (GitHub Releases API via MCP) to check recent deployments
- Returns structured root cause with confidence score and recommended fix steps
- Multi-tenant RBAC via Keycloak — teams are fully isolated including at the RAG layer

TECH STACK:
- Backend: FastAPI + Python 3.11
- Database: PostgreSQL + pgvector (vector embeddings stored inside Postgres — no separate vector DB)
- Auth: Keycloak + JWT (OIDC, multi-tenant RBAC)
- Queue: RabbitMQ + Celery (async document ingestion and AI inference)
- AI: LangChain + Ollama (Llama3 locally, swap to OpenAI for prod)
- Embeddings: SentenceTransformers all-MiniLM-L6-v2 (free, local)
- Frontend: React + Tailwind
- Infrastructure: Docker Compose (single `docker compose up`)

KEY DESIGN DECISIONS (I need to defend these in interviews):
1. Hybrid RAG (BM25 + Semantic): Pure vector search fails on exact technical terms (error codes, service names). BM25 handles exact matches, semantic handles conceptual matches. Combined via EnsembleRetriever([bm25, vector], weights=[0.4, 0.6])
2. pgvector over Pinecone/Qdrant: Same Postgres DB — no extra service. team_id filter at SQL layer enforces multi-tenant isolation structurally
3. Keycloak over plain JWT: Token refresh, revocation, RBAC, OIDC all out of the box
4. RabbitMQ + Celery: Honest answer — BackgroundTasks would work at MVP scale. Chose RabbitMQ to learn the pattern and build for scale (independent worker scaling, dead-letter queues)
5. Factory Pattern for AI/Embed providers: Swap Ollama for OpenAI without changing RAG code

DESIGN PATTERNS USED: Repository Pattern, Service Layer, Strategy Pattern, Factory Pattern, Command Pattern (MCP tools), Observer Pattern (notifications), Dependency Injection

BUILD PLAN: 4 weeks. Week 1: Auth + DB + Incident CRUD. Week 2: Embedding pipeline + Hybrid RAG + MCP tools. Week 3: Tests + polish. Week 4: CI/CD + demo video

RESUME LINE FOR OPTICA:
"Built an AI-powered production incident intelligence platform that reduces MTTR by surfacing similar historical incidents using hybrid RAG (BM25 + semantic search with LangChain EnsembleRetriever). Implemented Keycloak-backed multi-tenant RBAC with team-scoped vector retrieval, MCP-style tool calling (real GitHub Releases API integration), async document ingestion via RabbitMQ + Celery, and a full audit logging system — built on FastAPI, PostgreSQL, pgvector, and Docker Compose."
